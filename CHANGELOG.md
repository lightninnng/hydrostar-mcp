# Changelog

## 0.2.0 - 2026-10-27

- Ship source-informed container, tanker, and OC4-style column-platform recipes.
- Provide ten MCP tools and a shared CLI for planning, preparation, solving,
  cancellation, validated result reading, and configuration discovery.
- Add component mass/inertia models, passive damping matrices, and waterplane
  hydrostatics for the reference ship recipes.
- Publish native solver inputs, six-DOF amplitude/phase results, provenance,
  response figures, and an offline interactive gallery.
- Enforce semantic, equilibrium, geometry, topology, execution, and result gates.
- Package the project with portable examples, CI, MIT licensing, and source notices.
