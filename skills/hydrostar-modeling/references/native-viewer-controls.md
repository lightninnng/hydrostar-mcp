# 用鼠标和键盘操作 HydroStar 查看器

下列入口在 Windows HydroStar 8.2.0 实测。其他版本按当前菜单、安装手册和导出对话框核对。使用当前会话提供的 Computer Use 工具操作窗口，调用方式以该工具的说明为准。

## 从计算目录到导出文件

1. 先在命令行确认项目名、原生输入、结果版本及导出路径。Visu5D 需要本次求解的 `.hst`，StarViewer 需要装有实际 `.rao` 或 `.qtf` 的输出目录，HyView 需要含原生数据库和对应输入的项目根目录。复用已验收且来源一致的结果。需要补算时沿原生求解命令和既有面元门禁执行。
2. 绑定目标查看器，核对窗口标题、项目和当前对话框。优先按可访问性界面中明确的控件操作。Qt 工具栏、图形视口或弹窗的控件定位失效时，从目标窗口的新截图定位。菜单和弹窗可能各有一个截图区域，点击时使用对应区域的 `screenshotId`。切窗、缩放、开关弹窗或读取界面树后，按当前工具要求刷新坐标依据。
3. 鼠标负责选菜单、文件和视图对象，以及在绘图区拖动、旋转和滚动缩放。键盘用于已确认焦点的输入框和可见快捷键。替换路径或参数时先聚焦相应字段，再用 `Ctrl+A` 选中并输入。按字段实际行为用 `Tab`、`Enter` 或 **Apply** 提交，再读回数值和单位。Windows 选目录时，`Enter` 有时只进入该目录。看到目标路径后点 **选择文件夹**，随后核对查看器中实际加载的目录或项目。
4. 每次打开项目、切换结果、应用参数或保存后，先检查界面是否到了预期状态，再做下一步。窗口列表能单独识别模态对话框时，按标题绑定该窗口。录制切换或保存时若工具超时、窗口暂时不可用，先看新界面、原生日志和目标文件，再决定是否重试。若第三方浮层遮挡窗口，先确认目标窗口能否恢复。需要用户收起浮层时，等其确认后重新观察窗口和焦点。
5. 用查看器的保存或录制按钮写入工作目录，在命令行检查文件已写完、格式与尺寸相符，并重开成品检查边界、坐标或色标。保存来源、实际设置、操作入口和哈希。界面截图可用于识别控件和记录操作状态。成品以查看器输出的文件为准。

## Visu5D 网格原图

1. 切换构型先用 **File → Close**，等旧网格退出视口，再用 **File → Open** 载入本次 `.hst`。核对 **Mesh → Hull 1** 显示的湿面。半体按 HST 的对称定义使用 **Display xOz symmetry**，并检查左右舷是否齐全。带外部积分面的二阶 HST 可切换 **Free-surface** 检查环带和水线开口。
2. 在视口拖动旋转，用滚轮调整大小。看到全构型留有边距、关注部件和网格线可辨后，点工具栏 **Save image to file**。核对保存格式、文件名和目录，确认后打开实际保存的 JPG 检查有无裁切或旧网格重叠。

## StarViewer 曲线

1. 用目录按钮添加算例的结果目录，再在左栏选中实际加载的目录。多个目录都叫 `rao` 时，核对路径或文件列表。进 **RAOs** 选需要的自由度，文件列表筛到只剩目标文件时可用 `Ctrl+A`。选 **Module**、所需浪向和分面或叠图设置。分面标签拥挤时，用布局工具的 **Tight layout** 并复核各轴。
2. 二阶曲线用 **QTF** 标签，选定荷载分量、差频和幅值或相位。`plot in w` 的横轴是两波角频率的平均值。先从原表确定有效配对，再用工具栏的矩形缩放框选显示频段，避开无效配对的补零。
3. 点绘图区工具栏 **Save**，在格式栏选 SVG，确认焦点在文件名栏再输入路径。保存后检查实际曲线、图例、单位和所选浪向或差频。

## HyView 波面、运动和湿面压力

1. 用 **File → Open**（本机 `Ctrl+O`）选择含 HSMCN 和辐射绕射数据库的项目根目录，等待窗口标题切到目标项目。通过 **Sea State Parameters** 设实际波况，使用 **Wave Type Parameters** 选自由面和湿面压力分量。参数组出现绿色勾时点它应用，再核对回读值。本机周期输入按一位小数显示，记录实际接受的周期。
2. 点 **Play**，等刚体运动、自由面和压力等本次所需场量在日志中完成重建，并确认视口开始回放。带浪画面在网格显示树中保留 **Free Surface**，按需调透明度和 **Surface**，关闭 **Speed markers** 后取景。压力画面隐藏 **Free Surface**，选择 **Hull 1**，核对 **Coloring**、**Colormap** 和 **Scalar Range**。
3. 确认取景后点 **Record** 开始录制，再点一次并等待 **Save recording**，保存 MKV。**File → Save**（本机 `Ctrl+S`）保存项目设置。静态交付从 MKV 解码所选帧，记录帧号并核对原尺寸和像素。能核实求解时刻时单独记录。只掌握录制帧号时，将图标为代表帧。

导出格式、数据来源和数值验收见[直接导出与验收](direct-export.md)。
