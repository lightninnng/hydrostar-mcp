# 建模思路与质量检查

面元布局遵循[按结构特征建立水动力面元](panel-meshing.md)：柱式外形采用环带与周向对应，船体采用站位与剖面对应，浮箱和开口采用相容分块。四边形优先、平顺尺寸过渡及定量质量检查共同落实到生成与验收链路。

可靠的响应曲线由几何、质量、静水恢复、约束、耗散与离散共同决定。项目将输入显式分开，再在准备和执行阶段交叉检查，形成可复核的课程研究和工程简化分析流程。

## 1. 定义问题与分析层级

记录研究对象、装载、密度、水深、航速、频率与浪向范围，明确关注的自由度、周期和输出位置。当前流程执行单刚体、小运动、一阶频域分析，展示例采用零航速。阻力线性化同时记录规则波幅或谱参数。

涉及预张力、显著静态外载或大姿态变化时，应先求取相应平衡，并接入经过验证的原生静载卡片。当前可执行案例采用零静态外载平衡；该约束在输入生成阶段强制检查。

## 2. 选择几何层级

| 几何 | 用途 | 关键检查 |
| --- | --- | --- |
| 箱体、解析曲面体 | 生成器与方法基准 | 解析排水量、浮心、面板收敛 |
| 分段剖面船型 | 中体、圆舭、球鼻艏、艉部构型研究 | 体积、LCB、水线面、剖面连续性 |
| 并集方柱半潜 | 原创参数与网格研究 | 并集外表面、连接处、组合质量 |
| 圆柱扩底半潜 | 面元与细杆混合建模 | 柱体排水、切口、杆件浮力 |
| 单体 HST 导入 | 已有合规湿面网格 | 坐标、对称、自由面、法向及来源 |
| 通用几何前处理 | 型值表、DXF、实体 CAD、表面网格、标定图纸 | 显式单位、剖面对应、外部排水包络、全局自交、CAD 体积与浮心 |

[多来源几何建模与验收](geometry-sources.md)给出导入方式、放样选项和图纸尺寸标定流程。几何验收包与算例输入一同冻结，原生求解前再次核验来源文件的 SHA-256。

坐标为右手系，x 向船艏，y 横向，z 向上；自由面 z=0。旋转自由度按右手规则。单对称半体位于 y≥0；双对称四分之一体位于 x≥0、y≥0。浪向数值保留原生 HydroStar 约定，解释波传播方向时应结合原生坐标和输入设置。

分段船型放样生成湿面，非平面四边形拆成三角形。参照资料确定主尺度、静水标量和构型特征，局部线型按项目参数重建。实船分析应使用目标线型并检查敏感性。

## 3. 建立质量与静力账本

显式质量包含总质量（kg）、重心（m）、关于重心的六个回转半径参数（m）、来源和阻尼。组合质量支持箱体、竖直圆柱、点质量与给定惯性的刚体，通过平行轴定理归并。交叉项使用求解器带符号回转半径约定。

总排水为面元排水加 `Cm>0` 实体 Morison 杆件排水。`Cm=0` 的柱阻力补充只计阻力；成员用途与几何分工应逐项说明。初始静力检查要求：

- 质量与总浮力竖向平衡误差默认 ≤1%。
- 重心与组合浮心水平偏距默认 ≤0.05 m。
- 质量、惯性满足物理约束，原生 `hsmcn` 平衡诊断通过。
- 检查原生横摇、纵摇 GM，确认恢复方向与工况一致。

船舶模板由当前网格排水量配平，Gz 根据水线面静水量与目标 GM 反算，采用 `HYDSWPLANE`。半潜逐项组合结构、灌水压载、塔架/RNA 假设和对称底部配载。额外配载形成当前零预载平衡；真实系泊预载按目标系统补充。

## 4. 明确约束和耗散

刚度与阻尼矩阵的顺序为 surge、sway、heave、roll、pitch、yaw；运动方程统一使用 SI 和 rad。RAO 转角输出单位从原生文件读取，展示例为 deg/m。

船舶附加阻尼按干质量与未耦合静水恢复临界参考值的 5% 固定取值。半潜采用 Morison 阻力和底板等效线性耗散，明确假定相对速度幅值。目标对象可用衰减试验或参考响应标定。

曲面、球鼻艏和扩底柱补充了实际构型特征。一阶响应能够表现共振、峰谷和频率相关变化；有限幅非线性效应需采用相应扩展方法。

## 5. 网格与数值检查

生成器记录参数、源码哈希和外部网格来源。检查面板索引、面积、湿面位置、法向、平面性、公共边及允许切口。按构型定义预期湿面连通分量；半潜多个柱体由干结构和细杆连接，作为一个刚体运动。

`hslec` 提供实测湿面、水线面和水线段数量；`hschk` 必须给出七项完整零计数：零面积、自由面上方、自由面内、重叠、不一致、缺邻边及对称问题。

常规默认执行预算为 `(湿面板+水线面面板)×2^对称面数≤3000`。规划阶段保留水线面余量，hslec 后复核实测总量。超出时先优化网格或简化细节，确需提高预算时按具体算例取得明确授权，接受决定写入报告。

`λ≥8×最大面元边长`与长宽比 ≤5 另作几何筛查，有限水深波长用色散关系计算。超限返回具体数值与确认 token，由使用者审阅后继续。

## 6. 求解与结果验收

执行顺序为 `hsmsh（需要时）→hslec→hschk→hsrdf→hsmcn→hsrao`。授权、Fortran、交互等待、平衡与收敛异常均会中止链路，包含退出码为 0 的异常。超时与取消清理该算例进程树。

| 硬门禁字段 | 验收对象 |
| --- | --- |
| `semantic_input` | 完整参数与物理一致性 |
| `static_equilibrium` | 总浮力、质量、重心及原生平衡 |
| `mesh_geometry` | 几何积分、法向和已知参考量 |
| `mesh_topology` | hschk 七项完整零计数 |
| `module_execution` | 模块、日志、返回码与终态 |
| `rao_integrity` | 请求自由度、单位、频率/浪向、有限数值及哈希 |

幅值和相位一起保存。检查低频趋势、对称性、峰值位置与尖峰。相位在幅值近零处应结合幅值解释。固定物理参数，分别加密空间和频率，检查峰区稳定性。

## 7. 按用途给出结论

课程报告至少包含参数来源、假设、几何图、质量账本、门禁、响应和敏感性。工程简化分析还应补充目标几何、实际装载/惯性、约束/预载、阻尼依据及周期/RAO 对照。

`engineering_acceptance` 保存证据项。数值执行通过后，按目标用途补齐资料并给出适用海况与误差范围。[公开结果](results.md)记录本版本已完成的内容。
