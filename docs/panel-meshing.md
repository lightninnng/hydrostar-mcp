# 按结构特征建立水动力面元

本项目从结构的对称性、曲率方向和连接关系确定网格拓扑，再确定分段与尺寸。规则曲面优先使用连续的四边形网格带，节点沿几何特征逐一对应。四边形可以表现为随半径、截面和曲率变化的梯形；其形状、翘曲和尺寸过渡共同决定离散质量。

这套方法用于课程研究及工程简化的一阶水动力分析。原生求解采用实际保存的面元连接关系，图示直接读取该湿表面。面元的几何验收、数值执行和目标用途精度分别留下证据。

## 3000 面元预算界限

常规新模型默认按 **3000 个全体等效总面元**规划。总量包含湿面、水线面以及对称展开：N_total=(N_wet+N_waterplane)×2^sym，sym=0、1、2 分别对应全体、半体和四分之一体。规划估算和 hslec 实测各复核一次，独立检查使用的内部三角形另行统计。

保持 recommended_max_panels=3000，几何 max_panels 默认不高于 3000。初始网格通常低于该预算，并为自动水线面预留空间。达到预算时优先优化结构分区、节点对应、局部尺寸和必要的模型简化。

3000 同时作为提高执行预算前的审阅边界。确需超出时，列出具体算例的数量、用途、时间与内存需求，由用户明确授权后继续。当前批次已经授权的密网格保持原配置，作为有标识的研究参照；新模型采用上述默认预算。

## 同轴柱体与升沉板

圆柱、圆台、Spar 和同轴扩底构型优先沿轴向切分成环，再按相同周向相位等角分割。相邻环的第 i 个节点与第 i 个节点连接，形成贯通的经向网格线和有序环带。变截面的位置来自参数轮廓或 CAD 截面；同轴椭圆截面使用一致的极角对应，并保持原截面形状。

轴向环的位置同时考虑曲率、截面变化率和目标面元尺度。肩部、升沉板上下表面以及平均水线作为明确分区高程。水平板面在内外边界之间增加径向环带，周向节点与柱面及板外缘一致。各分区使用共享节点连接，尺度从柱面平顺过渡到板面。

底面设置规则中心区，外围通过四个相容分块与边界环连接。中心区和环带之间控制尺寸比，可形成全四边形 O 型网格。该布局把曲率方向、径向过渡和闭合方式写进生成器；轴线附近的单一高价极点可以通过分块展开。

规则环带适用于单一同轴、可按极角对应的外轮廓。贯通开口、多个不相连截面、显著偏心与局部附体采用相应分区，记录各分区的接口和拓扑选择。

## 船体、半潜和组合浮体

| 构型 | 首选面元拓扑 | 必须落实的几何对应 |
| --- | --- | --- |
| 曲面船体、FPSO | 沿纵向站位和剖面弧向建立四边形网格带 | 水线、龙骨、舭部、折角和艏艉特征逐一对应；端部采用受控渐变 |
| 多柱半潜 | 各柱独立环带，肩部径向分区，浮筒采用纵向分块 | 相交排水实体外表面、柱筒接头及共享边一致；细杆与势流湿面分工明确 |
| 浮箱、沉箱和多边形浮体 | 平面分块与映射四边形 | 保留原始角点；相邻块的公共边分段数和节点相同 |
| 带月池或贯通开口的浮体 | 外壁、内壁和连接底面的相容分块 | 开口内外轮廓、角点和水线闭环相对应；连接处平顺过渡 |
| 圆角浮筒、连接臂和管状构件 | 沿中心路径和截面方向布置网格带 | 截面相位、弯曲区、端部与接头分区明确 |
| 复杂 CAD 与局部附体 | 特征识别后的多块四边形，配合有记录的局部过渡 | 湿表面连续性、开口、尖端和交汇线分别验收 |

船体的站位密度随艏艉收缩和纵向曲率变化。剖面上的对应点围绕相同物理特征布置，平顺区域按弧长分段，折角保持为显式节点。渐变分段应同时检查相邻单元尺度和局部长宽比，端部收缩区通过加密站位、局部分块或有说明的三角形过渡连接。

半潜平台将每个柱体的环带与整体排水边界结合。柱筒交汇区先形成明确的外部湿面，连接界面的节点与边保持一致。由干结构或 Morison 构件连接的多个湿面分量，按同一刚体记录其物理连接与预期湿面连通分量。

复杂曲面会出现分块交汇和周向分段调整。过渡区可以使用有限的非规则节点和三角形面元，其位置、数量、原因和质量指标随报告记录。规则区域保持网格方向和节点对应，有助于复核曲率近似及后续网格加密。

## 面元质量与硬性验收

几何请求通过 panel_layout 指定生成策略。ring_bands 对同轴 CAD 采用环带与 O 型底面；station_bands 对沿 x 轴的单一平顺放样船体采用站位带；polygon_blocks 对等截面外体和单一贯通多边形开口采用特征对应分块；quad_dominant 用于其余 CAD 的分区四边形优先离散。triangular 保留为显式比较路径。输入表面网格保留已有四边形，水线裁剪产生的局部过渡单独计数。

环带可显式提供目标米制 axis_center_xy_m；默认中心取 CAD 排水体积的水平浮心。curvature_samples 决定周向分段，轴向和径向间距随 mesh_size_m 设置，并在报告中给出实际分段。底面中心区与外围环带同时约束尺度过渡。

站位带通过 longitudinal_cells 控制基础纵向分段，用 longitudinal_grading_blend 把线性分段与余弦分段连续混合。默认线性权重为 0.2，有限端封板旁的首末区间各细分一次，报告保存实际站位。水线和最低点分别对应，平顺剖面按两侧弧长取点。折角型线使用保留角点的特征分区路径。

平顺船体可通过 adaptive_stations 启用局部站位细分。它保留已有站位，按四边形翘曲和纵向边长定位细分区间，并平衡相邻纵向区间的渐变；每轮先检查湿面预算，报告记录新增站位和迭代结果。最终仍使用同一套完整几何门限。仅靠纵向细分无法满足曲面形状要求时，调整剖面分段、对应关系或分区后重建，并为水线面继续预留总预算。

生成器保存实际四边形和三角形的数量、比例及面元索引。内部三角化只服务于体积积分、自交等独立检查；求解文件与网格图继续使用实际面元边界。

几何门禁覆盖有限坐标、有效索引、正面积、凸性、共享边方向、完整水线闭环、预期连通分量、正排水体积和全局自交。曲面面元另检查边长比、内角、四边形翘曲以及共享边两侧的尺度变化。CAD 体积与浮心提供独立参照，水线和局部细节保留明确的误差上限。

相邻尺度采用面元面积平方根的比值，翘曲采用四边形两条内部三角面法向的夹角。所有指标同时给出定义、分位数、最大值和超限索引。阈值在几何请求中显式保存，验收程序使用同一份阈值；这些数值属于项目分析方案，应与构型、求解器要求和用途相适应。

自动生成的四边形优先路径执行最低四边形比例门禁。局部形状或尺寸超限时，调整分区、对应关系和离散密度，再重新验收。图形的规则程度与这些定量指标一起用于评估网格质量。

| 几何请求中的默认门限 | 数值 | 执行方式 |
| --- | --- | --- |
| minimum_quad_fraction | 0.8 | 自动生成的四边形优先路径逐面元计数 |
| panel_quality.max_edge_ratio | 8 | 每个面元最长边与最短边的比值 |
| panel_quality.min_corner_deg / max_corner_deg | 10° / 170° | 每个面元的三维内角 |
| panel_quality.max_warpage_deg | 5° | 四边形内部两三角面的法向夹角 |
| panel_quality.max_neighbor_size_ratio | 2 | 共享完整边的相邻面元面积平方根之比 |

具体算例使用自身更严格的阈值，并在请求和质量报告中完整列出。体积、浮心和拓扑仍分别执行独立门禁。相交判定在几何容差与数值舍入之间作明确区分，近乎共面的相邻环带在共同节点处相接时按实际交集判断。

## 结果比较与交付

建模记录说明原始资料、结构特征、分区选择、分段方式、尺寸过渡和局部过渡区。验收包保存源资料、参数、生成代码哈希、湿面、质量报告和科研格式的检查图。

实际 .hst、.rdf、.mcn、.rao 以及任务所需的 .spc、荷载和场量输入按[原生文件交付](native-delivery.md)逐项保存。随包提供文件用途、参数单位、依赖、执行顺序、状态与哈希，图表和动画对应各自原生输入与输出。

可视化首先采用当前版本手册默认、推荐的[原生与配套流程](native-visualization.md)。按内容选择 hview、hvisu、hsplt / StarViewer、HyView、HSprv → ParaView、StarSpec 及其他适用的官方入口。保存手册依据、核对、设置与导出记录；自定义工具用于有记录的补充制图、科研排版或转码。

网格改变后，计算输入与来源哈希随之更新，再完成原生网格、平衡、辐射绕射、运动和结果完整性检查。旧网格结果作为带版本的比较基线，新的展示图与动画对应各自实际计算的面元文件。

比较离散策略时保持质量、重心、惯性、恢复、阻尼与环境一致，比较幅值、相位和复数响应。声明工程精度时，使用对应构型的多档空间离散、峰区频率加密和参考响应形成证据。较少的频率点可先验证建模到求解链路，其范围在报告中明确给出。

CAD 分区、映射和四边形接口可参见 [Gmsh 官方手册](https://gmsh.info/doc/texinfo/gmsh.html)。本项目将几何布置与水动力面元的实际验收结合，并保留每个算例采用的方法。
