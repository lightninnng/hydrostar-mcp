# HydroStar 原生文件交付

原生输入与原生结果共同构成可继续使用的计算交付。科研图、动画和 JSON 数组帮助审阅，原生文件保留网格、工况、物理参数、荷载和结果提取设置。每个算例的交付清单逐项记录文件用途、依赖、哈希和验收状态。

## 文件及其对应关系

| 文件或目录 | 内容与作用 | 交付检查 |
| --- | --- | --- |
| 项目名.hst | 节点、原生面元连接、坐标与几何对称定义 | 与通过验收且实际求解的湿面哈希一致；四边形连接保留 |
| 项目名.rdf | 辐射绕射的频率、浪向、水深、航速及结果文件设置 | 工况与报告一致，引用的结果名与后续 .mcn/.rao 相容 |
| 项目名.mcn | 质量、重心、惯性、恢复、阻尼及实际采用的构件参数 | 参数来源、坐标、单位和装载假设明确，平衡及初稳性通过 |
| 项目名.rao | 运动或荷载的结果提取设置 | 区分输入指令与下列同扩展名的输出，提取量和参考点明确 |
| rao/*.rao | 原生响应或荷载的幅值、相位、频率、浪向与单位 | 与本次输入及发布数组逐项一致，完整性检查通过 |
| 项目名.spc | StarSpec 的海况、谱型、方向、RAO 路径、积分和统计设置 | 谱分析任务实际提供并检查该文件，说明海况来源、频率覆盖和插值方法 |
| .dft、.qtf 及二阶荷载提取输入 | 平均漂移、完整差频或和频的方法、配对频率及自由面积分设置 | 保存实际执行文件、原生复数荷载、有效配对与分量验收范围 |
| 实际采用的建网与场量输入 | 例如 .mri 建网指令、压力采样或自由面场点输入 | 保存已使用的实际文件，标明采样坐标、分量、单位与计算结果的关联 |
| 几何资料与验收记录 | 参数、型值表、CAD、已标定描线、来源清单与质量报告 | 可追溯到该 .hst；尺寸、单位、假设和代码哈希随包保留 |
| 复算所需的原生中间结果 | 各模块生成并被后续模块使用的数据库或结果文件 | 根据交付目标保存，或清楚列出由哪些输入和命令重新生成 |
| 原生可视化与媒体复现材料 | 实际查看/绘图设置、所需场点和数据库、原始图像/帧/视频及转码设置 | 按[原生优先流程](native-visualization.md)记录工具、原生核对状态、单位、色标、倍率与哈希 |

.rdf 是辐射绕射计算设置，实际荷载结果随原生数据库及相应提取输出保存。.spc 用于谱分析和统计后处理，其海况参数与 .rdf 的规则波频率、浪向设置分别记录。

## 执行顺序与文件状态

当前单刚体频域算例沿 hslec、hschk、hsrdf、hsmcn、hsrao 的顺序执行；采用 hsmsh 的建网路径先保存并执行建网指令。需要谱统计时，再以本次原生 RAO 及对应 .spc 调用 hspec。各命令使用当前安装版本要求的参数和工作目录。

交付说明给出可操作的工作目录、项目名、输入文件、调用顺序及输出位置。运行需要相应版本的软件和授权。每一阶段完成后检查原生日志、返回状态及所需输出，并执行相应质量门禁。

清单对每个文件记录已生成、已执行、已验证、待补充或本次不适用。已验证对应实际计算与检查证据。任务所需的网格、荷载、参数或谱文件缺失时，先补齐该项，再完成交付；缺少海况资料时明确待补充的波高、周期、谱型与方向等参数。

网格、物理参数和工况改变后重新计算关联结果，更新文件哈希与来源。新模型继续采用 3000 个全体等效总面元的默认预算，湿面、水线面及对称展开按同一口径计数。已有的密网格参照例按其具体授权配置保留。

二阶差频在完成一阶与运动求解后顺序执行 hsdft、hsamg、hsqtf、hsrao。外部积分自由面计入全体总预算，并保存覆盖、重叠、接口、形状及原生面元核对记录。

## 本项目的保存位置

公开算例的 inputs/ 保存实际原生输入，rao/ 保存原生响应输出；config.json、motions.json 及验收记录提供参数与结果的对应关系。压力和波面示例还保存其场量输入、原生输出与检查记录。文件状态和用途以各算例的记录为准。

## 核对依据

本项目对照本机安装包中的 Bureau Veritas《HstarManual.pdf》及《StarSpec_Manual.pdf》核对原生工作流。前者第 4、5、6 章分别介绍网格、辐射绕射和运动计算；后者第 3 章介绍 .spc 输入，第 4 章介绍 hspec 执行与统计输出。随 8.2.0 安装包的 StarSpec 手册中，PDF 第 29、33、40、47 页分别对应 RAO 文件路径、海况列表、积分设置和运行方法。

公开仓库保存本项目原创输入及计算结果。软件手册和官方教程使用本机安装包提供的版本。产品资料参见 [Bureau Veritas HydroStar](https://marine-offshore.bureauveritas.com/hydrostar-software-powerful-hydrodynamic)。
